# 🏠 Smart Home Control System

A simple Java-based console app built with Spring Boot to simulate controlling smart home appliances like **Light**, **Fan**, and **Air Conditioner** via command-line input.

---

## ✨ Features

- Turn appliances **ON/OFF**
- Set **Fan speed** (0 to 2)
- Set **Air Conditioner mode** (COOL / HEAT / OFF)
- View current **status of all appliances**
- **Turn off all appliances** with one command
- Console interface runs in a **background thread**
- Scheduled task turns off all appliances **annually on Jan 1 at 1:00 AM**

---

## 🛠 Technologies

- Java 21
- Spring Boot 3.4
- JUnit 5 & Mockito
- Lombok
- Gradle
- IntelliJ IDEA
